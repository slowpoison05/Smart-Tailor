# Smart Tailor

Responsive Next.js + TypeScript virtual fitting studio for women's blouses, salwar suits, dresses and gowns.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

The first release includes editable measurements, inches/cm conversion, a measurement-driven 3D garment foundation, local draft saving, CSV export, and an API boundary reserved for real AI try-on integration. The current 3D preview is an approximation, not a calibrated body model or sewing pattern. AI try-on is not connected yet.
